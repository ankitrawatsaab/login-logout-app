Login Logout App

A full-stack authentication application built with React, Node.js, Express.js, and MongoDB.

Features

User Signup

User Login and Logout

Password Hashing

JWT Authentication

Responsive UI

Toast Notifications

Tech Stack

React.js, Vite, Tailwind CSS

Node.js, Express.js

MongoDB, Mongoose

Axios, React Router, Sonner

Run Locally

Backend

cd backend
npm install
npm run dev

Frontend

Open a separate terminal:

cd frontend
npm install
npm run dev
